## Official files

Source: `https://pi.dev/press-kit`

- `official/logos/pi-logo-white.svg` — primary transparent white SVG (`https://pi.dev/logo.svg`)
- `official/logos/pi-logo-auto.svg` — black in light mode, white in dark mode (`https://pi.dev/logo-auto.svg`)
- `official/logos/pi-badge-dark.svg` — rounded dark badge (`https://pi.dev/favicon.svg`)
- `official/logos/pi-badge-dark-800.png` — locally rendered 800 px PNG
- `official/media/pi-social-card.png` — 1200 × 630 social card (`https://pi.dev/social.png`)
- `official/media/screenshots.zip` — original press-kit screenshot bundle
- `official/media/screenshots/` — extracted Tree View and Doom Extension screenshots

The upstream Pi repository is MIT licensed:
`https://github.com/earendil-works/pi`
